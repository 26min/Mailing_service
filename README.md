# Mailing Service

Сервис управления рассылками на Django.

## 📋 Функционал

- **Получатели** — CRUD для клиентов (email, ФИО, комментарий)
- **Сообщения** — CRUD для писем (тема, тело)
- **Рассылки** — CRUD для рассылок (даты, сообщение, получатели)
- **Отправка писем** — вручную через интерфейс с проверкой времени
- **Попытки отправки** — история успешных/неуспешных отправок (batch)
- **Главная страница** — статистика (всего рассылок, активных, получателей)
- **Аутентификация** — регистрация, вход, выход, восстановление пароля
- **Роли** — пользователь (свои объекты) / менеджер (все объекты, только просмотр)
- **Кэширование** — Redis для главной страницы

## 🛠️ Технологии

- Python 3.14.3
- Django 6.1.2
- Redis + django-redis
- Bootstrap 5
- Git / GitHub
